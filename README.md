# DEADLY KUPERFIELD

> THE WIZARD WHO SHOULD NOT HAVE PASSED MAGIC SCHOOL

![DEADLY KUPERFIELD](deadly_kuperfield.png)

## What is DEADLY KUPERFIELD?

A ridiculous but genuinely playable top-down 2D wizard action game built with
Python + Pygame. You are DEADLY KUPERFIELD, an overdramatic sorcerer full of
forbidden magic and bad decisions. Survive 4 waves of balloons, necromancers
and demons, then face **THE GREAT KUPER** himself in a two-phase boss fight.

No external assets. Everything — the wizard, the arena, the runes, even the sound effects — is generated procedurally with Pygame primitives and raw audio buffers.

## Requirements

- Python 3.10+
- pygame
